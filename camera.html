This won't work on a phone from a file.

You opened this as a local file. Phone browsers block two things on file://: the module import this page needs, and camera access — which requires a secure origin. Neither has a workaround on the device.

To try it on a phone, the page has to be on an https:// address. Drop this single file onto any free static host — Netlify Drop, Cloudflare Pages, Vercel or GitHub Pages all work, take about two minutes, and give you a link you can send to anyone.
